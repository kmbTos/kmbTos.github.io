# 風来のシレン2 — 鬼襲来！シレン城！ (NINTENDO64) 解析ツール

公開ページ: <https://kmbtos.github.io/N64_Shiren2/>

ゲーム内部の仕組みを調べて、その挙動をブラウザ上で再現したツールの置き場です。
いずれも **単一HTML・外部依存ゼロ・外部通信なし** で、`file://` で直接開いても動きます。

## 収録ツール

| ツール | 内容 |
|---|---|
| [地形シミュレータ](terrain-sim/) | 各階の部屋タイプ分布と店/モンスターハウス等の**実効出現率**を計算 + モンテカルロで検証。シード指定でフロアのミニマップを生成 |

今後ここに追加していきます。

## ROMのデータについて

**このリポジトリにゲーム本体のデータは含めていません。**

同梱しているのは、フロアごとの出現率などの**数表(ゲームバランスのパラメータ)だけ**です。
これだけでも確率の計算とミニマップの地形生成は動きますが、
アイテムや店の商品にかかわる表は含めていないため、**店やモンスターハウスが出るフロアでは
それより後ろの地形と階段の位置がゲーム内と食い違います。**

お手元のROM (`.z64`) をページにドロップすると、そこも含めて一致するようになります。
ドロップしたROMはブラウザ内で読むだけで、どこにも送信されません。
