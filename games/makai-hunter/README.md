# 魔界の狩人 - MAKAI HUNTER v1.0

SFC魔界村の操作感とモンハンの狩りシステムを合わせた2Dアクションゲーム。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。依存なし。

### 操作

- **← →**: 移動
- **Z**: 攻撃 / メニュー決定
- **X**: ジャンプ / 戻る
- **C**: 回避ローリング
- **A**: 回復薬を飲む
- **↓**: しゃがみ / 討伐後は剥ぎ取り
- **Enter**: ポーズ / クエスト撤退
- **Delete**: セーブデータ初期化（タイトル画面のみ）

### ゲームシステム

#### 武器
- **斬**: 尻尾を切断可能（切断後、追加で剥ぎ取り）
- **突**: リーチが長い
- **打**: 弾かれにくく、頭部を殴るとスタン状態に（打武器装備時のみゲージ表示）

**属性**: 火・水・雷。モンスターによって弱点が異なる

#### 部位肉質
- 各部位で肉質が異なる
- 肉質が低い(0.5未満)と攻撃が**弾かれる**
- 弾かれると相手が硬直するチャンス

#### スタン・怯み
- 打武器で頭を殴り続けるとスタンゲージが溜まる
- ゲージMAXで気絶 → 攻撃し放題のチャンス
- 各部位への蓄積ダメージで怯み発動（怯むたびに閾値が上昇）

#### 怒り状態
- HPが一定以下になるとモンスターが怒り狂う
- 攻撃頻度と威力がアップ

#### 防具
加工屋で防具強化レベルを上げられます（Lv0～5、各レベルで9%被ダメージカット）

#### 狩りループ

1. **ガルドス（火吹き鳥）** ← 鉄武器で討伐 → 火属性武器作成
2. **アクアロス（水獣）** ← 火属性で攻撃 → 水属性武器作成
3. **ガンロック（岩甲獣）** ← 打武器+水属性で攻撃（斬・突は弾かれる）→ 防具強化素材
4. **ボルテウス（雷竜）** ← 水属性で攻撃 → 雷属性武器作成

**重要**: ボルテウスを倒すと雷属性武器が作れます。これでガルドスを瞬殺できるようになり、素材周回が高速化します。これが「効率化のための狩りループ」です。

### セーブ
自動保存されます（ブラウザのlocalStorage）。同じブラウザで遊ぶ限り、データは保持されます。

Delete キーでセーブデータを初期化できます（タイトル画面のみ）。共有PCや作り直し用に活用してください。

## トラブル

- **ブラウザのキャッシュが古い**: Ctrl+Shift+Delete でブラウザキャッシュをクリア、または Shift+F5 で強制リロード
- **Deleteキーが機能しない**: 一度タイトル画面に戻ってから試してください
- **セーブが消えた**: ブラウザのLocalStorageが有効になっているか確認してください（シークレットウィンドウではセーブされません）
